# CampusNet Enterprise Network

Enterprise campus network simulation built with Cisco Packet Tracer.

## Project Goals
- Hierarchical Core, Distribution, and Access architecture
- VLAN segmentation across four buildings
- Inter-VLAN routing using Layer 3 switches
- OSPF dynamic routing
- HSRP gateway redundancy
- EtherChannel between core switches
- Guest network isolation and security ACLs
- Connectivity and failover testing

## Buildings
- Building A: Administration and Server Farm
- Building B: Faculty and Classrooms
- Building C: Labs and Research
- Building D: Library and Guest Network

## Repository Structure
- `campusnet-enterprise.pkt`: Packet Tracer topology (save from Packet Tracer)
- `topology/`: topology diagrams
- `configs/`: device configuration backups
- `docs/`: design and testing documentation
- `screenshots/`: verification screenshots

## Status
